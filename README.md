# hxyfront-62002 剧场灯光 · 灯位与 Cue 工作台

排练用的单页灯位/Cue 工作台：灯具台账、舞台平面灯位图、场景预览、Cue 调光台同页操作。

## 功能

- **灯具台账**：维护灯具编号、通道号、色片、默认焦位、亮度预设、灯区（面光 / 侧光 / 逆光 / 效果光），支持加灯、删灯。
- **Cue 顺序**：新建 / 复制 / 删除 / 上下移调整触发顺序；每个 Cue 绑定每盏灯的调光值（0–100）与焦位覆盖。
- **三联动切换**：切到某条 Cue，舞台平面（光束随灯位/灯区/亮度绘制）、场景预览（正视光池）和右侧调光台一起切换。
- **未保存保护**：推子、焦位覆盖、场景名、版本备注有改动时出现脏标记；切换 Cue 前弹窗选择「保存并切换 / 放弃改动并切换 / 继续编辑」，刷新页面也会提醒，内容不丢。
- **版本备注**：随 Cue 保存（如导演要求、待走位确认、版本 A/B）。
- **灯区筛选**：只影响灯具列表、调光台表格与平面/预览的高亮显示；**已选灯具勾选状态始终保留**，不受筛选影响。
- **导出排练清单**：按当前灯区筛选导出 `.txt`（含灯具表、每个 Cue 的调光值条形图、焦位覆盖与版本备注），文件名带筛选灯区。

## 技术栈

React 19 + Vite + TypeScript（无 UI 框架，SVG 手绘舞台平面与场景预览）

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62002
npm run build    # 生产构建
npx tsc --noEmit # 类型检查
```
